# Third-party code

This plugin is derived from
[SmoothPixels/cursor-accent](https://github.com/SmoothPixels/cursor-accent)
by Jean Alvarado, GPL-3.0-or-later. `recolor.py`, `Service.qml` and
`tools/install-menu-entry.sh` are adapted from that project.

It bundles `src/cursor_utils.py`, `svg/`, and `config/` from
[rtgiskard/bibata_cursor](https://github.com/rtgiskard/bibata_cursor),
pinned to commit `f4ccfe8abb63fddc7b3ce51a866fd8378395cb3d`, licensed
GPL-3.0-or-later. It builds hyprcursor and Xcursor themes from
[ful1e5/Bibata_Cursor](https://github.com/ful1e5/Bibata_Cursor)'s SVG
artwork, also GPL-3.0-or-later.

Because that source is copyleft, this whole repository is GPL-3.0-or-later
too (see LICENSE).
